# ct-lung-cross-cohort-benchmark

Code for a cross-cohort reproducibility benchmark of CT-based survival prediction in non-small cell lung cancer: what ComBat corrects, and what it does not.

## Summary of findings

Using five public TCIA CT collections (781 imaging entries, 741 unique patients, 633 with survival data), we held preprocessing, feature extraction and model class fixed and compared ComBat-corrected with uncorrected representations in a head-to-head external validation. ComBat removed the marginal distributional difference between cohorts (mean absolute standardised difference 0.755 → 0.012) and restored the direction of the transported risk score (calibration slope −0.327 → +0.815). External discrimination did not improve: the joint model reached a C-index of 0.507 (95% CI 0.431–0.580) against an internal cross-validated 0.582 (95% CI 0.565–0.598). Target-cohort recalibration reduced the Brier score by 40–52% without changing discrimination, and the feature–outcome associations themselves differed between cohorts (top-ten component overlap 10%). Cross-cohort reproducibility therefore comprises orthogonal failure layers — feature-space orientation, baseline hazard and discrimination — that require separate reporting.

## Reproducing the analysis

**Environment.** Python 3.10 was used for the reported analysis, with the package versions pinned in `requirements.txt` (scikit-learn 1.7.2, lifelines 0.30.0, scikit-survival 0.25.0, neuroCombat 0.2.12).

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**Data.** Download the five TCIA collections first and arrange them under a single working directory; see `docs/README_data.md`. No imaging data or individual-level derived feature tables are redistributed in this repository.

**Pipeline order.**

1. `scripts/run_lungmask_all_v2.py` — select one representative CT series per patient and segment the lungs (`lungmask`).
2. `scripts/extract_radiomics_v2.py` — PyRadiomics features (107 per patient).
3. `scripts/extract_embeddings.py` — frozen InceptionV3 embeddings (2048 per patient).
4. `scripts/merge_master_features.py`, `scripts/clean_features.py` — assemble and harmonise the feature table.
5. `scripts/combat_correct.py` — ComBat correction (batch = collection, no covariates).
6. `scripts/audit_distribution.py`, `scripts/audit_after_combat.py` — distributional audit before and after correction (Fig 2).
7. `scripts/survival_step3.py`, `scripts/survival_step3_nocombat.py` — four feature sets, internal and external evaluation (Table 1).
8. `scripts/calibration_dca.py`, `scripts/calib_inside_lung1.py`, `scripts/recalibration.py`, `scripts/recalibration_nocombat.py` — calibration and decision curves (Figs 3–4).
9. `scripts/brier_compare.py`, `scripts/brier_nocombat.py`, `scripts/brier_constrained.py`, `scripts/diag_brier.py` — Brier scores and calibration diagnostics (Table 2).
10. `scripts/cv_bootstrap_ci.py` — 50-seed × 5-fold internal cross-validation bootstrap.
11. `scripts/shap_stability.py`, `scripts/feature_stability_intervention.py` — cross-cohort coefficient agreement and the stability intervention (Tables 4–5, Fig 5).
12. `scripts/decay_decomp.py` — decomposition of performance loss (Table 3).
13. `scripts/longshort_external.py`, `scripts/longshort_ci.py` — LUAD-CT-Survival diagnostic evaluation (Table 6).

Scripts expect the inputs in the working directory; path constants at the top of each file should be adjusted to the local layout. Random seeds: PCA `random_state = 0`, cross-validation `random_state = 42`, bootstrap `seed = 42`.
