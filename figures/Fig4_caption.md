**Figure 4. Decision curves for the joint and embedding models.**
Net benefit as a function of threshold probability (0.05–0.90 in steps of 0.05) at 365, 730 and 1095 days. Rows: (a–c) external cohort (NSCLC-Radiogenomics, n = 211) with the original models, showing the embedding-only model (Deep, blue) and the joint model (Joint, orange); (d–f) external cohort with the joint model after linear recalibration fitted on the external cohort; (g–i) internal LUNG1 out-of-fold joint model (n = 422) from five-fold cross-validation. Reference strategies are treat-all (black dashed) and treat-none (grey solid, net benefit = 0). Recalibration was fitted for the joint model only, so Deep curves are shown only for the original external model; the internal row shows the joint model only, matching the analysis that was run. Y axes are fixed at −0.2 to 0.5 across all panels. Decision curve analysis is shown as graphical evidence: numeric net-benefit values are not reported because the analysis pipeline produced the curves without a numeric output table, and values were not read off the images. DCA, decision curve analysis.
